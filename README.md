# IRCTC Clone - Frontend

A frontend clone of the IRCTC (Indian Railway Catering and Tourism Corporation) website, built as a practice project to strengthen HTML, CSS, and JavaScript fundamentals.

## About

This project replicates the user interface of the IRCTC website, including key pages like login, registration, ticket booking, and gallery. It focuses on layout, styling, and responsive design.

## Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactivity

## Pages Included

- Home (`index.html`)
- Login (`login.html`)
- Registration (`registration.html`)
- Ticket Booking (`ticket_booking.html`)
- Gallery (`gallary.html`)
- Contact (`contact.html`)

## Note

This is a frontend-only implementation built for practice and learning purposes. A full-stack version of this project (with Java backend and database integration) is available separately.
